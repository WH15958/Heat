# Heat MVP 系统验收清单

本清单用于 `heater1`、`heater2`、`pump1`、`microwave1` 及双泵微波热水流程的实机放行。软件测试不能替代现场确认。执行人必须遵守实验室 SOP 和设备说明书，不得为了完成表格绕过门控、急停或保护装置。

## 使用规则

- 按 Gate 0 到 Gate 6 顺序执行；前一 Gate 未通过，不得进入下一 Gate。
- 结论填写 `PASS`、`FAIL` 或 `N/A`。`N/A` 必须写批准人和理由。
- 证据填写照片编号、日志路径、API 输出、`run_id` 或仪器记录编号，不能只写“正常”。
- 出现立即停止条件时，先按 SOP 使设备安全，再记录问题。页面请求成功不能替代物理状态确认。
- 本清单不授权化学实验；集成阶段只使用实验室批准的水或低风险替代液。

## 立即停止条件

- 串口身份、站号或序列号不确定；读回与 HMI/实物不一致。
- 任一设备返回 `False`、timeout、`read_ok=false`、未知状态或非零故障码。
- 泄漏、堵塞、明显蒸汽、不可控气泡、回流、虹吸或管路异常变形。
- 液位不足、探头暴露、微波空载、炉门/联锁/接地/通风未确认。
- 温度超过实验室批准上限；本水测试达到 `65 C` 时立即停止。
- stop 后泵仍转动、微波启动位未清除，或功率/电流未归零。
