## 3. 分阶段标定步骤

### 3.1 通信与只读检查

1. 核对控制器电气接口和线序，不凭连接器外形将RS232当作TTL或RS485。
2. 确认串口只有一个控制端占用；使用厂家调试终端时，Heat不得同时占用该串口。本次归档未运行压缩包中的程序。
3. 先查询并记录当前坐标、输入位、运行状态及原始回复。短帧、多余字节、未知状态或超时均记为异常，不用旧坐标填补。
4. 确认查询本身不运动；记录静止读取的次数及失败数。静止读取成功不代表运动期间通信稳定。

### 3.2 平台工作零点与方向

1. 先检查运动路径、现场停止手段及实际限位接线，核查上电自动运行/自动回零设置；平台无光电原点，不执行机械寻零。不要为探测设置而盲目重上电。
2. 在可确认的安全范围内，以现场确定的保守速度和小位移核对正负方向、实际位移、停止及限位行为。不得直接使用手册示例速度或90 mm长行程。
3. 采用上方30 mm已知距离的方法取得方向与脉冲换算。面板清零与状态输入位的关系未核验，不将“原点/负限位有效”的读数视为已经触发真实开关。
4. 保存外圈对准点、各圈目标坐标和本次人工建立基准的记录；返回工作坐标0只在位置持续可信时使用，不代替传感器寻零。
5. 按事先填写的次数验证往返工作零点，记录每次实际对准误差；失败不标为通过，不以重新连接恢复位置可信度。转盘自身的机械原点仍单独按既有规则验证。

### 3.3 四圈与全盘瓶位

1. 保持转盘在已确认的机械零点，从当前外圈对准点逐步向内标定。核对运动线是否通过转盘中心，是否能在安全行程内覆盖四圈。
2. 每圈记录实测平台绝对坐标、位移及管口相对瓶口的偏差。30/60/90 mm只作为模型参考，实测不符时查明原因，不强行移动到理论坐标。
3. 如果各圈起始瓶不共线，分别标定转盘起始角/目标脉冲。若存在偏心等导致同圈平台位置也须调整，逐瓶记录差异，在确认可重复定位之前不假定“一圈一个平台坐标”。
4. 清点各圈实际瓶位数、确认编号方向，核对整圈角度/脉冲换算。旧每瓶12000脉冲和12瓶配置只作历史参考，不自动继承。
5. 在下方瓶位表为每个实际瓶位增加一行，覆盖所有拟用位置。不能只验证每圈起始瓶就宣布全盘通过。

### 3.4 换圈路径与水测

1. 先空载、再装空瓶验证路径，检查管口、瓶口/瓶盖、支架、转盘、软管拉力与限位。涉及换圈、回零和收尾的路径均需覆盖。
2. 两轴顺序运动，不同时运行。现场确定“先转盘后平台”“先平台后转盘”或需要中间避让点的安全路径，记录每段目标、顺序和限制；未确认之前不执行自动换圈。
3. 水测前沿用既有液路要求：新鲜确认蠕动泵CH3/CH4停止、两注射泵空闲、三通阀NC废液位，完成现场确定的滴液等待，再移动。
4. 两轴均到达目标且确认停止、现场对准通过后才允许接样。控制器坐标和停止读回不等于实际瓶口对准或管路排空。
5. 停止、限位、通信失联的处置分别验证并记录；失联不能假定软件仍能停止硬件，现场需有独立停机手段。失败后禁止自动补走、换瓶或继续接样。
