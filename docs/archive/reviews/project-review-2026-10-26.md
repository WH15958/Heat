## 确认的问题与修复

行号对应本报告所附分支工作区，后续修改可能使行号移动。

### F1 — P1：手动请求取消后过早释放实验注册锁

- 位置：`src/web/device_io.py:5`；调用方 `src/web/api/devices.py:249`、`src/web/api/syringe_pumps.py:17`、`src/web/api/valves.py`。
- 触发：持有注册锁的 HTTP 请求正等待同步工作线程，此时请求任务取消；线程无法被 asyncio 取消并继续操作设备。
- 影响：原来的 executor await 立即退出并释放锁，后续实验/控制可能与仍在执行的操作重叠。
- 证据：ASGI 请求 + 可阻塞假设备，覆盖加热器启动、泵停止、微波启动、阀切换、注射泵停止，并分别让工作线程成功/异常。重复取消后注册锁原先提前可用。
- 修复：统一手动调用桥接，用 shield 保留工作任务；取消时等待实际线程结束并消费结果/异常，再传播取消。未将同步驱动改为异步，也未绕过原有锁。
- 验证：`tests/test_audit_safety_boundaries.py:37`；修复前失败，修复后通过。转盘原有等效保护保留。硬件实际取消/停止时序仍须水测。

### F2 — P1：恢复目录不可读可能被当作没有恢复锁

- 位置：`src/experiment/microwave_program.py:101`、`src/web/api/guided.py:46`。
- 触发：恢复记录目录存在但枚举遭遇权限错误；Python 3.10 的 `Path.glob()` 可能吞掉该错误并给出空结果。
- 影响：微波托管/引导批次的恢复状态未经读取就被判定不存在，手动启动保护可能失效。
- 修复：严格枚举，仅忽略目录不存在；权限和其他读取错误返回存储不可用，阻止启动但保留停止入口。
- 验证：`tests/test_audit_safety_boundaries.py:80`，分别注入两类目录的枚举错误，确认启动返回 503、没有启动设备，停止可用。F1/F2 初始 12 个回归场景全部失败，修复后相关组合套件 67 项通过。

### F3 — P2：损坏样品历史被重写，扩展列被丢弃

- 位置：`src/science/sample_record.py:41`。
- 触发：追加或删除时读取到缺列/重复表头、不完整行、多余列、破损引号；或合法旧文件含额外实验室列。
- 影响：原先宽松解析和固定列重写可能丢失原始坏数据或合法扩展列，破坏追溯；自动编号不能可靠排重。
- 修复：写入、删除及编号使用严格 CSV 校验，错误保留原文件；解析/编码错误按存储失败处理；兼容 BOM，保留扩展列并补齐缺少的标准列。默认非严格查询保持历史兼容。缺失/零字节文件沿用既有空文件行为。
- 验证：`tests/test_audit_sample_integrity.py:20`、`:32`、`:43`、`:51`。初始 7 个场景失败，存储/metadata/删除/桌面保存重试组合 220 项通过；最终增加表头引号错误及非严格查询保留此前已读 ID 的兼容覆盖。执行已完成但样品写入失败时仍标记 persistence error，不改写执行结果。

### F4 — P2：迟到 REST 进度覆盖 WebSocket 终态或清理锁

- 位置：`frontend/src/views/ExperimentPage.vue:451`、`:685`。
- 触发：REST 请求先发出，随后 WS 确认 completed/failed/cleanup_pending，旧 REST 最后到达。
- 影响：页面可重新显示 running，或清除较新的清理锁提示。
- 修复：WS 进度/结束事件作废在途旧请求，响应同时核对实验选择与请求代次。
- 验证：`frontend/tests/experimentProgressOrdering.test.ts` 中终态、清理锁和迟到失败用例；修复前复现，修复后通过。

### F5 — P2：进度读取失败被静默忽略

- 位置：`frontend/src/views/ExperimentPage.vue:251`、`:685` 及顶部警告/控制按钮。
- 触发：后端断开或进度读取超时，旧快照仍显示正常状态。
- 影响：用户可能把旧瓶位/停止读回当作当前确认；旧 idle/paused 状态仍允许尝试启动/恢复。
- 修复：明确标记状态未确认并提供刷新，保留快照供停止操作使用，禁用启动/恢复；请求超时 6 秒，同一选择合并在途轮询，避免每秒新请求不断作废慢响应。
- 验证：前端状态测试覆盖失败、恢复、慢请求、超时和旧错误；浏览器关闭隔离后台后确认警告出现、启动禁用，截图 `disconnected.png`。

### F6 — P2：图形编辑缺失参数/等待对象时生成不兼容 YAML

- 位置：`frontend/src/experiment/document.ts:45`、`frontend/src/views/ExperimentEditor.vue:173`。
- 触发：导入省略可选 `params`/`wait` 的配方，首次填写日志内容、等待、嵌套 settings，或添加第一段微波参数。
- 影响：YAML 1.1 的隐式路径创建产生 `!!omap`，编辑器退到只读图形限制，后端拒绝参数结构；新建空数组不是 YAML 节点时也无法继续添加段。
- 修复：缺失父对象显式创建普通 YAML 映射/序列节点；首次创建微波段列表也使用序列节点。
- 验证：浏览器实际复现并在修复后成功保存/重新打开；`experimentDocument.test.ts` 覆盖首次参数、等待、嵌套映射和段列表。`frontend/editor-before.log` 留有失败证据。

### F7 — P2：模板批次无法处理省略或 null 的 metadata

- 位置：`frontend/src/experiment/batch.ts:68`。
- 触发：合法模板没有 metadata，或显式为 null，生成条件时先写普通 JS 对象再按 YAML 节点设置字段。
- 影响：抛出 `Expected YAML collection at metadata`，无法生成批次配方。
- 修复：创建 YAML 映射节点后写入批次/组/样品序号，保留其余生成语义。
- 验证：`frontend/tests/batch.test.ts` 新增两种输入的回归；`frontend/batch-before.log` 记录修复前失败，修复后通过。

### F8 — P2（测试）：就绪探测超时导致误报并遗留隔离子进程

- 位置：`tests/test_desktop_host.py:478`、`:515`。
- 触发：真实空设备子进程启动时，单次只读 IPC 查询超过测试设置的 0.5 秒；测试没有在总 20 秒期限内重试。清理请求若发于 starting 状态，后台按原语义不执行停机，测试之后只等待 stopped。
- 影响：软件回归偶发失败，可能遗留独立测试后台并占用端口，使后续测试跳过。
- 证据：`desktop-readiness-failure.log/xml`、`desktop-readiness-child.log`；当次全套为 1990 passed、1 failed、1 skipped。后台日志证明实际已启动；对该测试子进程执行认证 status/shutdown/commit_exit 后确认正常退出，没有强杀进程。
- 修复：只读就绪查询在原总期限内容忍 TimeoutError；清理期间等待到 ready 后再请求 shutdown。未改变产品 IPC 超时或自动重试设备控制语义。
- 验证：`desktop-retry.log`，桌面专项 42 passed，随后再次运行完整回归。
