## 已知通信事实

- 通信协议：Modbus-RTU。
- 默认串口：9600 baud，8 data bits，1 stop bit，无校验。
- 默认站号：1。
- DB9 通信接口：3 = 485A，8 = 485B。
- Excel 里的 `40001` 风格地址是人类可读保持寄存器地址；代码必须转换为 PDU 地址。
- Excel 工作表名称为 `26.6.`，有效数据范围为 `B2:G143`。
- Word 说明书未给出 Modbus 细节；通信事实以 Excel 为准，设备安全和操作语义以 Word 为准。

## 地址换算

实现时使用统一 helper：

```text
pdu_address = human_address - 40001
```

示例：

| Excel 地址 | PDU 地址 | 说明 |
| --- | ---: | --- |
| `40001` | `0` | 手动段 1 加热温度 |
| `40106` | `105` | 电流 |
| `40118` | `117` | 物料温度浮点数第 1 字 |
| `40151` | `150` | 控制字 |

禁止把 `40151` 直接传给 `ModbusRTUProtocol`。

注意：当前 `ModbusRTUProtocol.read_holding_registers()` 和写寄存器接口都使用 PDU 地址，不接受 `40001` 风格地址。`40118`/`40119` 的浮点字节序和字序未在 Excel 中明示，不能仅凭现有通用 helper 推定为已实机确认。

## 说明书安全事实

- 型号：`MKM-AH1E环形聚焦单模微波化学合成仪`。
- 额定电压：AC220V / 50Hz。
- 输入功率：1.3 kW。
- 额定微波功率：400 W。
- 额定微波频率：2450 +/- 50 MHz。
- 内部微波发生器最高电压：4200 VDC。
- 测温范围：0-300 C。
- 温度传感：说明书勾选光纤温度传感器。
- 温控模式：说明书勾选多段可编程逻辑控制器 PID 温度控制模式。
- 安装供电要求：AC220V +/- 5%，50Hz，设备必须可靠接地。
- 安装环境应干燥、通风良好，避免腐蚀性气体、导电粉尘、爆炸性气体、潮湿和粉尘。
- 设备四周应保证大于 30 cm 的散热空间。
- 安装和维修必须由具备资质的电气专业人员执行。
- 通电时禁止维修；断电后检查或维修前必须等待内部高压电容放电完毕。
- 如发生异常或危险情况，应尽快切断设备工作电源。
- 严禁炉门未关时启动微波。
- 炉门未关到位时，HMI 会提示“门未关严”，此时设备无法启动微波输出。
- 不得在运行过程中打开炉门。
- 严禁空载或极少量物料时使用。
- 弱吸波物料不论多少，说明书均按空载处理。
- 严禁放入与加热物料无关的物品；金属物严禁放入箱体内。
- 箱体发生损坏或变形时不得使用。
- 运行中必须有人不间断看护。
- 使用最高温度 300 C，禁止超温使用。
- 不得随意更改设备上各种仪表的出厂设定值。
- 说明书描述“压力报警”：使用微正压反应瓶时，测得压力达到设定值会强制停止微波；Excel 未给出压力寄存器。
- 说明书状态界面出现“散温不畅”故障文案；Excel 仅给出 `40112` 故障状态寄存器，未给出故障 bit 语义。

## 数据类型和单位说明

- Excel 中所有参数、状态整数均标为 `16位无符号整型`，`40118`/`40119` 标为 `32位浮点型`。
- Excel 未标出温度、功率、电流的比例系数。Word 说明书只给出测温范围 `0-300 C` 和额定微波功率 `400 W`，不能据此推导寄存器比例。
- 手动参数中的温度类字段应先按摄氏温度语义命名，但量纲比例需待实机或厂家确认。
- 手动参数中的功率类字段、状态 `40108` 实时功率在 Word HMI 中描述为“当前微波功率百分数”；参数寄存器是否也是百分数仍待确认。
- `40106` 电流在 Word HMI 中描述为当前仪器工作电流；单位和比例未给出。
- 时间寄存器按字段名拆成时、分、秒，不在底层协议层合并写入。

| 地址 | 类型 | 名称 | 建议字段 |
| --- | --- | --- | --- |
| `40106` | 16 位无符号整型 | 电流 | `current` |
| `40107` | 16 位无符号整型 | 物料温度 | `material_temperature_raw` |
| `40108` | 16 位无符号整型 | 实时功率 | `power_percent` |
| `40109` | 16 位无符号整型 | 运行时 | `runtime_hours` |
| `40110` | 16 位无符号整型 | 运行分 | `runtime_minutes` |
| `40111` | 16 位无符号整型 | 运行秒 | `runtime_seconds_part` |
| `40112` | 16 位无符号整型 | 故障状态 | `fault_code` |
| `40113` | 16 位无符号整型 | 当前段 | `current_segment` |
| `40114` | 16 位无符号整型 | 当前模式 | `current_mode_code` |
| `40118` / `40119` | 32 位浮点型 | 物料温度浮点数 | `material_temperature` |

实现建议：

- 优先读取 `40118`/`40119` 浮点温度。
- 浮点读取失败时回退到 `40107` 整型温度，并在状态中标记数据来源。
- `40118`/`40119` 读取可以先复用现有 Modbus float helper 做软件层假设，但必须在代码注释或测试命名中标明“待实机确认字序”。
- `runtime_seconds = hours * 3600 + minutes * 60 + seconds`。
- 不在代码中解释未知故障码；先暴露 `fault_code`。

## 控制字 `40151`

`40151` 是 16 位控制字。

| bit | 名称 | 权限 | 说明 |
| ---: | --- | --- | --- |
| 15 | 恒速率 | 只写 | 选择恒速率模式 |
| 14 | 自动功率 | 只写 | 选择自动功率模式 |
| 13 | 手动功率 | 只写 | 选择手动功率模式 |
| 12 | 微波启动 | 读&写 | 启动或停止微波输出 |
| 0-11 | 未标注 | 空 | 不使用 |

实现约束：

- 不对未标注 bit 赋予含义。
- start 写控制字前必须明确模式。
- stop 的写入值必须在 smoke test 中确认；初始实现建议只在 fake protocol 中验证，不直接实机使用。
- 因 bit15-bit13 标为只写，避免依赖 read-modify-write 保留旧模式位。
- Word 只确认 HMI 上“微波未启动”按钮可开启或停止微波系统，未说明 Modbus stop 应写入的完整控制字。

建议 mask：

```text
CONSTANT_RATE = 1 << 15
AUTO_POWER = 1 << 14
MANUAL_POWER = 1 << 13
MICROWAVE_START = 1 << 12
```

## 原始资料差异与命名注意

- 当前草稿曾把 `40118` 描述为浮点数“高字”；Excel 只列出 `40118`/`40119` 为同一个 32 位浮点值，未说明高低字或字节序。
- Excel 参数块写“自动升温”，控制字 bit14 写“自动功率”；Word 自动模式描述为温度设定 + PID 调功。02 实现中建议用清晰注释或别名保留这组差异。
- Word 说明书配置项勾选光纤温度传感器，但 HMI 文案仍泛称“红外测温仪或者光纤测温仪”。本机接入默认按光纤测温配置处理。
- Word 出现压力显示、压力曲线和压力报警；Excel 未列出压力当前值、压力报警阈值或压力曲线寄存器。
- Word 出现“散温不畅”故障显示；Excel 只给 `40112` 故障状态，未提供故障码或 bit 对照表。
- Word 确认门控开关联锁会阻止未关门启动；Excel 未列出门状态寄存器，不能在软件状态中伪造 door_closed。

## 未确认项

- 温度、功率、电流寄存器是否存在比例系数。
- `40112` 故障状态的 bit 含义。
- `40114` 当前模式的枚举值。
- `40065` 和 `40067` 等空权限单元格是否继承“读&写”。
- `40118`/`40119` 浮点数的字节序和字序。
- `40151` stop 应写 `0`，还是只清 bit12；实机前必须确认。
- 压力报警在说明书中出现，但协议表未看到明确压力寄存器。
- 门控开关状态是否存在可读寄存器。
- HMI 中“控制方案”“起始段”“结束段”等配置是否有未提供的 Modbus 地址。
- 自动模式、手动模式、恒速率模式之间切换时，是否需要额外确认位或延时。

## 给 02 的交接

- 新建协议常量时只使用 PDU 地址，建议提供 `human_to_pdu(40001)` 这类 helper 并覆盖 `40001 -> 0`、`40151 -> 150`。
- 不要把 Excel 空权限格默认为可写；`40065`、`40067` 先在 fake protocol 中覆盖为待确认字段。
- `40151` 的启动控制必须显式选择模式位和 bit12；不要依赖 read-modify-write 读取只写模式位。
- stop 只做软件假设和 fake protocol 测试，不对真实设备执行写入，直到 smoke test 确认写 `0` 或清 bit12 的语义。
- 真实微波启动能力在配置和 API 层继续默认禁用；手动控制、YAML 自动化和 WebSocket 接入留给后续编号任务。
- 状态读取先暴露原始 `fault_code`、`current_mode_code`，不要编造故障文案或模式枚举。
- 安全联锁事实来自 Word，但协议没有门状态、压力状态寄存器；02 不应在驱动状态中伪造这些字段。
