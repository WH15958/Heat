01 / 当前结构

水平段上方开口，末端保持完整圆孔

软管从水平段的上开口放入；自由端先穿过圆滑弯头，再从竖直圆孔向下伸出。末端侧壁闭合，不再开侧缝。打印件负责支撑、导向，液体始终在原软管内流动。

旋转件：瓶盘

圆形底板＋单圈有底浅杯瓶座，一体打印。中央安装区用螺钉连接现有转动平台。

静止件：支架

C 形底座＋立柱＋悬臂＋导向槽，一体打印。底座放在台面上，避开转动件与电机线缆。

换瓶动作

完成一组实验后停泵，转盘转到下一瓶并确认到位，再开始接样。出液头位置保持固定。

支架不设压条、拆分夹套或细小卡扣。瓶盘和支架各自一体打印，两者互不连接。C 形底座的稳定性还需结合实际尺寸、重量和软管拉力验证。

03 / 软管导向细节

从上开口槽过渡到闭孔弯头

弯头和竖直段按闭孔画出。软管外径决定槽与孔的配合，软管自身的可弯曲程度决定弯头半径。

先试打印一小段“U 槽＋弯头＋圆孔”，检查穿管、自然弯曲、孔内支撑清理和管口滑动情况。孔径与弯曲半径确认后再打印整个支架；不靠挤扁软管来固定。

06 / 安装与验证顺序

先量接口，再试短段，最后定整体

实物测量

先量瓶子、转台安装面和孔位、软管外径、机座与电缆外廓，并拍带标尺的俯视与侧视照片。

小样试配

试印一个瓶座和一段导管槽 / 闭孔弯头，确认放瓶、穿管、孔内清理及软管是否滑动。

安装定位

螺钉安装瓶盘；C 底座放在静止台面。穿入软管，再放入水平槽，对准瓶口中心和净空。

水测确认

先空载 / 装瓶检查整圈避让，再按停泵—换位—到位—接样验证；同时观察残滴、软管拉力与支架稳定性。

转一整圈均无碰撞，线缆不被拖动。
支架受正常软管拉力时不滑动、不倾倒。
孔内软管自然弯曲，无明显折扁。
每个瓶位都能对准，管口高于最高瓶沿。

目前未生成可直接打印的最终模型。材料适用性、一体打印可行性、载荷及装置实机行为由实物试验确认；控制器既有接线保持按实验室实际装配处理。
