# Heat 液路与设备工程设计参考

本文是长期工程参考，说明当前 MVP 液路边界、死体积、预灌和标定方法。现场操作与放行以 [mvp_system_acceptance_checklist.md](mvp_system_acceptance_checklist.md) 和实验室 SOP 为准。

## 1. 当前 MVP 拓扑

```text
水/替代液 -> pump1 CH4 (CW) -> 入口管路 -> 10 mL 微波反应容器
微波反应容器 -> 出口管路 -> pump1 CH3 (CCW) -> 开放耐热收集容器
```

当前双泵流程按反应容器约 2/3 液位设计。CH3 停止时必须经实测证明出口仍常压连通；若泵头会夹闭唯一出口，必须先增加独立常开排气/泄压路径，现有 YAML 不得运行。

## 2. 必须记录的液路参数

| 字段 | 含义 |
| --- | --- |
| `line_id` | 液路唯一编号 |
| `device_id` / channel | 泵和通道 |
| direction | 设定方向及现场实际方向 |
| tube material/model/ID | 软管材料、型号和有效内径 |
| length | 实际参与输运的有效长度 |
| calibrated_flow_ml_min | 当前液体和系统条件下的实测流量 |
| dead_volume_ml | 管路、接头和相关腔体的死体积 |
| arrival_delay_s | 目标液体到达观察点的延迟 |
| prime_volume_ml | 置换到稳定组成所需预灌量 |
| residual_volume_ml | 停泵/排液后的残留量 |
| pressure_path | 常压出口或独立泄压路径 |

软件中的 `flow_rate` 是设备设定/报告值，不是外部流量计实测。泵管老化、装夹、背压、液体黏度、温度和气泡都会改变实际流量。

## 3. 死体积和理论时间

圆管理论体积：

```text
V = pi * (ID / 2)^2 * L
```

当 `ID` 和 `L` 都以 mm 输入时，结果为 mm3，除以 1000 得到 mL。实际系统还包含接头、探头、反应器入口/出口和可压缩管段，必须通过置换或称重实测修正。

理论输运时间：

```text
t_min = target_volume_ml / calibrated_flow_ml_min
t_s = 60 * t_min
```

预灌量至少包括从液体起点到目标边界的有效死体积和经实验批准的置换余量。不要把填充入口管路的液体误算成已经进入反应容器的投料。

## 4. 三层流量标定

每条活动液路在相同软管、装夹、液体、温度和背压条件下至少重复三次。

| 层级 | 接法 | 目的 |
| --- | --- | --- |
| 泵出口 | 泵出口直接进入量筒或称重容器 | 建立泵头和泵管基线 |
| 长管末端 | 接入真实长管，在系统入口前收集 | 测量管路弹性、气泡和到达延迟 |
| 系统端 | 接入反应器及出口，在安全收集端测量 | 纳入接头、反应器和背压影响 |

推荐步骤：

1. 核对液体、密度、温度、软管型号、通道和方向。
2. 排尽可见气泡，先把目标液体送到本层标定起点。
3. 以稳定转速运行一段足以减小启停误差的时间，同时计时。
4. 用校准天平称质量，按 `V = mass / density` 换算体积；量筒仅作为精度满足时的替代。
5. 计算 `Q = V / t`，记录三次结果、均值、极差或标准差和相对偏差。
6. 更换标定层级后重新排气，不沿用上一层结果。
7. 在正向进液和反向抽液各自的真实方向、真实系统背压下分别标定。
8. 结果填入唯一验收清单；超出实验室容差时检查装夹、管路磨损、气泡、泄漏、回流和背压后重做。

## 5. 精确切换与预灌

没有自动阀门时，液体切换是人工动作，必须把时间零点和收集边界写入 SOP。

1. 在废液端预灌，直到目标液体已越过全部上游死体积且出口组成稳定。
2. 记录泵启动时间、液体前沿到达时间、切换收集容器时间和泵停止时间。
3. 需要精确体积时，以系统端标定流量乘有效运行时间，并用切换前后的称重结果复核。
4. 为避免混合带污染，单独测量旧液体到新液体的过渡体积；过渡段进入废液，不计入有效样品。
5. 切换液体、方向或软管后重新确认虹吸、回流和停泵夹闭情况。

仅靠管路几何体积不能保证精确切换。需要更高精度时，应增加在线质量/流量测量或经过验证的常开阀路，并作为独立硬件与软件任务评审。

## 6. 当前水测试与未来设计

当前可执行拓扑只包含 CH4/CW 进水和 CH3/CCW 出水。多前驱体、多入口、自动阀门、在线混合和自动分段收集属于未来设计，不能把概念通道直接替换进当前水测试 YAML。

未来扩展前至少需要明确：材料兼容性、阀默认安全位、断电状态、交叉污染、混合体积、堵塞检测、常压泄放、驱动/API/YAML 动作和实机 smoke test。规划器或 Campaign 可以推荐参数，但不能直接绕过人工批准控制硬件。

## 7. 记录与可追踪性

每次标定或集成运行至少关联：配置 commit、设备/软管编号、液体批次、原始称重、密度、时间、实测流量、死体积、残留、操作者、问题编号、`run_id` 和 `sample_id`。`samples.csv` 负责样品追踪；标定原始数据和照片按实验室记录系统保存，并在验收清单中引用。
